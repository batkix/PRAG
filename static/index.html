Comment fonctionne PRAG ?

PRAG utilise deux modèles d'IA complémentaires :

CLF
Classification
Détermine si un mois est optimal pour le semis (F1-score optimisé)
REG
Régression
Prédit le rendement attendu en tonnes/hectare (RMSE minimisé)

Les modèles GPU (réseaux de neurones) sont entraînés sur Kaggle avec T4 GPU. Le meilleur modèle est sélectionné selon un score composite : 70% performance + 30% vitesse d'inférence.
